# 🕊️ 매일 만나 하늘빛 (Daily Manna Haneulbit)

> **하늘빛기쁨교회 초등부 아이들을 위한, 주중 매일 3분 영적 케어 앱**

주일 예배만으로는 아쉬운 한 주. 초등부 아이들이 월~금 매일 3분씩 QT와 퀴즈를 하고,
선생님은 12명의 참여 현황을 한눈에 챙기고, 부모님은 자녀의 신앙 성장을 함께 지켜볼 수 있도록
만들고 있는 학생·선생님·부모님 3계정 통합 모바일 앱입니다.

---

## 📱 이 앱은 무엇을 하나요

- **학생**은 매일 3분 QT, 2단계 WWJD 퀴즈를 하고, 달란트를 모아 "하나님의 전신갑주"를 사고 강화하며,
  감사 보물상자·1:1 마음 톡·비밀 마니또 같은 소소한 재미로 신앙 습관을 만들어 갑니다.
- **선생님**은 12명의 참여 현황을 대시보드 하나로 보고, 학생 계정을 등록하고,
  주간 QT 템플릿·공지사항·유튜브 영상을 올리고, AI가 걸러낸 위험한 표현을 검수합니다.
- **부모님**은 자녀의 월간 영적 자람 리포트를 보고, 같은 알림장·캘린더를 확인하고,
  집에서 실천한 말씀 미션에 도장을 눌러 줍니다.

지금은 **UI/UX가 실제 사용자 흐름 그대로 완성된 상태**이며, 실제 데이터베이스(Supabase)와
AI 기능(TTS, 이미지 생성, 언어 감지)은 아직 Mock(가짜 데이터)으로 동작합니다. 자세한 구현 현황은
[아래 기능 목록](#-기능-구현-현황)에 정리해 두었습니다.

## 🛠️ 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| 프레임워크 | React Native + Expo SDK 57 (`expo start --web/ios/android`) |
| 언어 | TypeScript (일부 초기 화면은 JavaScript/JSX) |
| 내비게이션 | React Navigation (Expo Router에 내장된 Stack Navigator) |

| 스타일 | RN `StyleSheet`, `src/constants/theme.ts`의 공용 디자인 토큰(색상/반경/그림자) |

## 📂 프로젝트 구조

```
src/
├─ navigation/         # RootNavigator → Student/Teacher/ParentNavigator
├─ screens/
│  ├─ auth/            # 역할 선택, 학생/선생님/부모님 로그인
│  ├─ student/          # 학생 화면들 (Xxx Screen.tsx + xxxData.ts + xxxStyles.ts)
│  ├─ teacher/          # 선생님 8개 관리 화면
│  └─ parent/           # 부모님 4개 화면
├─ data/                # 여러 계정이 함께 쓰는 공용 Mock 데이터 (공지/캘린더, 영상, 안전 필터 등)
├─ lib/supabase.ts      # Supabase 클라이언트 (아직 .env 미설정 시 경고만 출력)
├─ components/ui/       # 공용 버튼/카드 등 디자인 시스템 컴포넌트
└─ constants/theme.ts   # 색상·반경·그림자 등 디자인 토큰

supabase/
├─ schema.sql           # 전체 테이블 + RLS 정책 (모든 화면의 Mock 데이터에 대응)
├─ seed.sql             # 계정 없이도 채울 수 있는 기준 데이터(전신갑주 카탈로그)
└─ README.md            # Supabase 프로젝트 연결 가이드
```

각 화면 폴더는 `XxxScreen.tsx`(레이아웃) · `xxxData.ts`(타입/Mock 데이터) · `xxxStyles.ts`(스타일)로
철저히 분리돼 있습니다. 자세한 코딩 컨벤션은 [`CLAUDE.md`](CLAUDE.md)를 참고하세요.

## 🗄️ Supabase 연동 (다음 단계)

지금까지 만든 모든 화면의 Mock 데이터에 대응하는 테이블·RLS 정책·인증 전략은
[`supabase/schema.sql`](supabase/schema.sql)에 이미 준비돼 있습니다. 실제 프로젝트를 만들고
연결하는 방법은 [`supabase/README.md`](supabase/README.md)를 따라 하면 됩니다. 아직 어떤 화면도
실제 Supabase 프로젝트에 연결돼 있지 않습니다.

다만 아이가 모은 **달란트·전신갑주·한 줄 다짐**은 [`src/lib/localStore.ts`](src/lib/localStore.ts)를 통해
기기(AsyncStorage)에 저장되므로, 앱을 껐다 켜도 그대로 남아 있습니다. 나머지 화면(QT 기록, 감사 보물상자,
마음 톡 등)은 아직 앱을 다시 켜면 초기 Mock 값으로 돌아갑니다.
