# 🕊️ 매일 만나 하늘빛 (Daily Manna Haneulbit)

> **하늘빛기쁨교회 초등부 아이들의 주중 영적 케어를 위한 모바일 애플리케이션**

---

## 📱 프로젝트 소개

- [cite_start]**대상:** 하늘빛기쁨교회 초등부 (1~6학년 중심, 총 12명) [cite: 3, 9]
- [cite_start]**목적:** 일주일에 한 번 드리는 주일 예배를 넘어, 주중에도 매일 3분 Daily QT, 퀴즈, 게이미피케이션(하나님의 전신갑주)을 통해 하나님과 동행하는 습관 형성 [cite: 4, 15, 38]

---

## 🛠️ 기술 스택 (Tech Stack)

- [cite_start]**Frontend:** React Native (Expo SDK 51+) [cite: 162]
- [cite_start]**Backend / Database:** Supabase (Auth, Database, Storage) [cite: 164]
- [cite_start]**AI Integration:** OpenAI (TTS AI 음성, Moderation API 비속어 감지) [cite: 137]

---

## ✨ 주요 기능

### 👦 1. 학생 계정 (Student)

- [cite_start]**AI 2D 아바타 & 전신갑주:** 아이 사진 기반 아바타 생성 및 에베소서 6장 전신갑주 강화 [cite: 38, 128]
- [cite_start]**3분 Daily QT:** 다정한 AI 음성(TTS) 말씀 듣기 및 한 줄 나눔 [cite: 16, 17, 137]
- [cite_start]**2단계 WWJD 퀴즈:** 올바른 행동 선택(1단계) ➔ 성경 요절 매칭(2단계) [cite: 47, 223]
- [cite_start]**1:1 마음 톡 & 응원 스티커:** 선생님과의 1:1 고민 상담 및 친구 간 칭찬 스티커 반응 [cite: 24, 292, 299]

### 🏡 2. 부모님 계정 (Parent)

- [cite_start]**영적 자람 리포트:** 자녀의 월간 큐티 이행률 및 성찰 기록 조회 [cite: 74]
- [cite_start]**가정 미션 도장:** 집에서 수행한 말씀 실천 미션 확인 도장 승인 [cite: 58, 73]

### ✝️ 3. 선생님 계정 (Teacher / Admin)

- [cite_start]**12명 통합 대시보드:** 아이별 큐티/퀴즈 참여 현황 실시간 모니터링 [cite: 3, 9, 30]
- [cite_start]**주간 템플릿 일괄 등록:** AI 음성 자동 생성 기능을 통한 주간 콘텐츠 편리한 관리 [cite: 137, 140, 141]
- [cite_start]**AI 아동 보호 필터링:** 비속어 및 교회 정서에 맞지 않는 게시글 사전 검토 [cite: 22]
